# 📊 TrustBank Customer Churn Analysis

## 📌 Project Overview

An interactive Power BI dashboard built to analyze customer churn, retention patterns, and customer behavior.

The goal of this project is to identify important churn patterns and provide actionable insights that can help improve customer retention.

---

## 🎯 Business Objectives

- Analyze customer churn and retention
- Identify customer segments with higher churn
- Understand churn trends over time
- Compare retained vs exited customers
- Identify patterns that can support retention strategies

---

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- SQL
- Data Modeling
- Data Visualization

---

## 📈 Key Metrics

- **Total Customers:** 10,000
- **Exited Customers:** 2,037
- **Retained Customers:** 7,963
- **Churn Rate:** 20.37%

---

## 🔍 Key Insights

- Customer churn varies across different customer segments.
- Certain months show significantly higher customer exits.
- Customer characteristics can help identify higher-risk segments.
- Retention analysis provides opportunities for targeted customer strategies.
